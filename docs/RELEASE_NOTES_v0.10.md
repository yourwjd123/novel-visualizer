# v0.10.0-beta.1 本地测试版

2026-11-17。本次同步GitHub源码、此前已编译界面与测试说明；不启动任何构建，不创建Release。

## 工作流与接口

设置 → 生图模型配置：选择/编辑已有图片连接，在其下添加工作流预设。导入ComfyUI API JSON后，本地自动填写映射，可自行修改并校验保存。每份预设记录参考图数量；同一连接共用地址、密钥。同数量可指定默认项，自定义节点可另设首选。旧配置保留在兼容入口。

设置 → AI选项：可开启默认语言模型辅助，默认关闭。仅导入或主动识别时调用，不发送原文、聊天历史、旧提示词、图片与原文件名；使用用户前置规则和固定识别指导。本地可确定的字段保留，AI补充歧义结果经结构校验，失败不重试。

开始生图 → 本次生图窗口：按实际参考图数量在指定连接匹配预设，选择后确认才提交。没有匹配不自动换服务、不丢图或补旧图。窗口只提供服务/工作流决策，不重复展示方案与图片。有效LoadImage输入必须全部被本次参考图覆盖。参考图不足时需使用对应数量的工作流，不能仅删映射字段。

复杂自定义编码器、开关分支和固定控制图不保证自动识别，可能需要手工整理工作流；不自动改写工作流结构。普通图片API仍仅文生图。云端需要兼容ComfyUI接口、正确鉴权、已安装节点及模型；本轮没有真实GPU验证。

## 小说与制作界面

书架封面“⋯”提供删除，须输入完整书名。默认将完整项目移入账户的小说回收站，成果、过程资料和阅读数据全部保留；设置中的小说回收站可恢复或书名验证后永久删除。直接永久删除无恢复功能。项目之外用户复制的文件不删除，运行任务时禁止删除；存在符号链接的项目拒绝破坏性操作，需用户先处理。

小说回收站位于账户目录 `小说回收站/删除记录ID/`，其中 `删除信息.json` 保存元信息，`项目/` 保留完整原目录；恢复保留原项目ID。相同目录或ID冲突时阻止恢复，不覆盖。

资产库缩减常驻控制区，章节、建议与整理状态集中；低频入口收纳，选择卡片后显示批量操作。场景制图用双栏同时展示方案和主预览，分隔条可拖动/键盘调整，窄窗口上下排列；资产制图同步方案和预览样式。场景关联卡集中显示图号、出镜、状态与编辑，候选缩略图切换主图；原有本地素材导出与外部图片导入保留。
