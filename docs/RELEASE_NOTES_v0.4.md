# v0.5.1-beta.1 · 源码测试版（非稳定正式版）

本次仅发布源码，包含已编译界面。**不启动 Windows 构建，不提供此版本 EXE 或免安装运行包。** Windows 工作流现为仅手动触发，版本标签不会自动构建。

- 原文附件一文件一章；粘贴录入确认独立章节或合并到指定章节首尾，章节卡支持堆叠切换、归档恢复。
- 章节资产独立构建，候选审核、重要等级和情节映射；状态副卡支持前向继承及章节/情节手工选择。
- 单轮自动任务；独立梗概咨询；资产及提示词 AI 补全由用户逐项采用，不自动覆盖。
- 接口前置提示词、token 估算、实际上限和用量记录、JSON 校验及 TXT/MD 导出。
- 无图资产使用文字；有图 ComfyUI 需参考图映射。普通兼容图片 API 仍仅文生图，不支持通用图像编辑。

Linux 本地 92 项后端测试及真实 Qt WebEngine/QWebChannel 桌面流程通过；未发生付费模型调用，未完成本版本 Windows 构建或实机验证。详细边界见 TEST_REPORT.md。

运行：安装 Python 3.12 及 requirements.txt 依赖，运行 start_windows.bat 或 python main.py。无需为使用本包重新编译前端。

升级前备份用户资料。既有原文、资产、个人模板、密钥和历史任务保留；旧项目规则只读存档，不再发送。
