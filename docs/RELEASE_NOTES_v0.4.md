# v0.4.0-beta.1 · 测试版（非稳定正式版）

本项目只将已有小说文本可视化，不包含小说创作、续写或正文改写功能。

## 本次更新

- 重新实现四个横向工作标签：原文与情节、视觉资产库、场景插图、成果集。系统侧栏可收起，AI 助手为独立可移动缩放浮窗。
- 导入文本不自动调用模型。原文对照、候选情节卡、粗中细拆分、手工编辑/拆分/合并、撤销、范围校验与人工确认形成完整第一步。
- 资产档案、多张参考图、情节插图分开管理；参考图支持主图选择、画廊与可恢复回收站，无固定到期删除。
- 最终插图展示关联资产，可编辑本情节的服装/状态；缺失项由用户确认是否接受，生成时保存设定与状态快照。
- 统一语言/图片模型配置，各节点独立连接、密钥、参数及可编辑模板；保留真实 API 和 ComfyUI 调用。
- 适配系统 DPI、显示缩放及窗口尺寸。访客可先进入工作区，开始操作时再登录或创建本地账户。
- 旧项目目录和 schema 2 保持兼容；账户设置导出不含密钥，嵌套图片任务绑定导入时重建连接 ID。

## 验证

- 本地 Python 自动化测试 72 项通过。
- 编译后的 React 工作区在真实 Qt WebEngine + QWebChannel 环境中通过端到端检查：账户、导入、拆分确认、资产编辑、画廊回收/恢复、对话、选定成果和节点设置。
- 原生自动化检查覆盖 1920、1440、1024、760、640、390 宽度及 125%/150%/200% 缩放组合。
- Windows 自动构建通过后，本页附带 Windows x64 解压运行包、源码和构建验证材料；请确认构建状态后下载相应附件。

## 使用与限制

- Windows 运行包：完整解压后双击 NovelVisualizer.exe，保留 _internal 目录；不需安装 Node.js、Docker 或 Python。
- 源码包：包含已编译界面，安装 requirements.txt 后运行 main.py。修改前端源码才需要 Node.js。
- 升级前备份用户数据。已有目录可在账户窗口中重新选择。没有将旧项目上传到仓库。
- Windows 包未代码签名；自动构建与冒烟检查不等于各种用户机器上的实机验证。
- 模型质量取决于用户配置；没有使用付费供应商完成全型号端到端测试。兼容图片 API 当前仅文生图，参考图输入需正确映射 ComfyUI 工作流。
- 失败和未知结果不自动重试或切换服务；远端任务可能仍运行，取消本地等待不会全局中断共享 ComfyUI。
- 离线演示中的图片为预置示例，不代表用户模型调用的输出。
