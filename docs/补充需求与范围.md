# 对话确认的补充需求与 0.1 范围

原始需求文档是设计参考，开发授权来自用户最后的“现在可以开发一个基础测试版”。源码按用户随后指定的 GitHub 仓库发布。

| 已确认补充 | 0.1 实现与边界 |
| --- | --- |
| 本地账户创建、修改、删除、设置隔离 | 已实现；删除归档项目，账户不是 OS 安全隔离 |
| 导入导出账户设置，严格排除凭据 | 白名单与已知凭据脱敏；背景文件和连接地址不共享 |
| 节点背景提示词、输出 token、温度可改 | 每个节点独立覆盖，影响后续请求，历史快照固定 |
| 分段上传原文，同项目资产共享 | 已实现；资产人工录入，状态生效范围用文本表达 |
| 附件提示、大小预估、设置开关，纯文本默认不提示 | 已实现；历史附件再次发送也确认；无法估计费用 |
| 设置按钮及 UI 设置 | 明/暗/跟随系统、字号、背景图片与透明度、恢复默认 |
| 横向卡片、右侧详情、多轮对话与手工定稿 | 已实现；窄窗口工作台滚动，未做自由流程编排 |
| 所有 LLM 节点多轮确认，可完全人工输入 | 5 个阶段节点均支持，确认后才纳入下游上下文 |
| 对话和模型文本 TXT/MD 导出 | 完整、仅模型、最近输出、所选文本、当前方案 |
| 清楚目录树、原始文档与各类附件可查看 | 已实现；外部修改正文可重读，其他反向同步待开发 |
| 历史版本保留与手工改动追溯 | 确认方案、资产档案、任务上下文/参数快照保留 |
| 开发后再询问是否发布 Git 仓库 | 本地源码与测试先完成，经用户提供目标仓库后发布 |

原始需求的完整 MVP 尚未全部完成，详细未完成项见 README。尤其尚未实现云端图片适配器、自动结构化提取入库、段落证据定位和资产时序引擎。
