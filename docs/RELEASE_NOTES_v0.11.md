# v0.11.0-beta.1 本地测试版

2026-11-18。本次同步GitHub源码、此前已编译界面与测试说明。不启动任何构建，不创建Release。

## 整本成果与多图

成果集在同一页展示整本小说，按当前章节和情节原文顺序排列，没有章节二级菜单。同情节多图合为一张卡片，显示数量；点击图片进入翻页查看，可编辑/删除当前一张，卡面删除作用于整组。批量选择卡片包含该组所有图片，导出按正文顺序涵盖所选图片。

场景候选缩略图可勾选多张后批量选为成果/取消选定，单张也可操作。取消后候选原件保留，成果记录归档；再次采用优先恢复该记录，重复选择不新建相同来源记录。替换图片保留原件，但原候选不再被标为仍在采用。旧单张成果保留ID和文件；可唯一确定且内容一致时补充来源关联，不猜测不唯一的对应关系。

阅读场景预览仅显示已选成果，同情节一个入口、组内翻页。已停用“阅读显示候选图”，旧开关不再生效。资产仍按主卡/副卡浏览，主卡无图时打开第一张有效副卡；没有有效图片的资产和空分类不生成图片入口。

## 阅读与原图

阅读浮层点击图片直接放大，放大按钮保留。所有共用大图入口提供全屏，图片组支持左右箭头、键盘方向键，换图重置缩放。全屏时Esc先退出全屏，再按关闭大图，回到原阅读浮层；关闭按钮始终可用。修复重复点击当前章节目录项后图像栏停刷的问题。

## 书架与章节

竖版书架封面保持比例完整缩放；三点菜单支持更名、换封面、恢复封面、删除。可拖动排序，保存到当前账户设置，更名和换封面不切换当前制作项目，也不重命名目录。

原文对照中的堆叠章节卡右侧改为三点菜单，提供更名/删除；拖动排序，不增加常驻按钮。章节ID、原文、书签和历史任务保留，自动副卡继承按新顺序计算，人工指定不改写。有未保存情节编辑时提示先保存再排序。

批量原文导入原本已支持，保持多选/多文件拖入、一附件一章不变；单文件原生选择入口不变。

## 数据与验证

不改变SQLite结构。章节顺序保存于项目配置 `chapter_order`；书架顺序保存于账户设置 `bookshelf_order`。成果仍使用 `06_最终成果/成果索引.json`，删除仍归档，不删除原始候选、参考图和任务记录。旧用户资料与个人提示词保留，模板版本仍6.0。升级前建议备份用户目录。

137项后端测试与四套实际Qt WebEngine/QWebChannel桌面流程通过，含整本跨章节画廊、多图、全屏与退出、书架封面/更名/拖动、章节更名/拖动、批量导入及副卡无主图预览。未调用真实付费模型或云端GPU，未做Windows构建或用户机器实测。源码包包含已编译界面，运行需要Python和requirements依赖。
