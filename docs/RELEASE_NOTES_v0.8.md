# v0.8.0-beta.1 · 源码测试版（不启动构建）

- 原文导入/粘贴入口迁移到视觉资产库；附件始终一章，粘贴归属确认保留。导入后按本次与合并后章节展示字数，分阶段估算输入token，不调用模型。
- 资产卡面及批量审核改为状态下拉，保留待确认/已确认/已锁定；锁定冻结编辑，需要先解锁，无新增锁定设置。
- 默认提示词升级至6.0：道具图不出现人体或持握者；场景图允许弱化背景人群，前景无突出或遮挡主体的人物。扩写指导同步更新，个人模板保留。
- 场景生图有图资产只用参考图编号，无图使用视觉文字。兼容图片API明确接受后才改用文字描述；ComfyUI缺少映射时不提交。
- 拆分同次请求默认AI关联已有资产，使用简短ID/别名/身份索引；“AI选项”可改本地字符匹配或仅手工。无效关联移除并标注，有效情节保留，不自动重试；手工增删及原有确认记录保留。
- 素材导出将MD和参考图平铺同级目录，每次选择新版本或覆盖指定版本；覆盖保留额外文件，先准备再替换。资产与情节参考图原件不受影响。
- 外部场景图片可上传或拖入，复制到当前情节候选，经用户确认后进成果集，候选可移除/恢复而不删除原文件或已确认成果。加载方案时先等待就绪，避免异步加载覆盖刚输入的文字。

本版已完成本地编译验证；本次同步GitHub源码与此前编译好的界面，不启动新构建、不创建Release。源码包包含已编译界面，仍需Python与requirements依赖。未调用真实付费模型；第一人称关联效果、用户模型/ComfyUI及Windows环境仍需用户测试。token仅为本地字符启发式估算，非账单或上限保证。
