# v0.9.0-beta.1 测试版说明

本次同步 GitHub 源码与此前已编译界面。没有启动任何构建、Windows 打包或创建 Release。

## 使用入口

启动 → 书架 → 点击小说封面 → 阅读 → 进入制作。每本小说仍对应原有项目；侧栏和制作流程保持现有结构。封面卡仅显示书名，章节数量、最近阅读位置及制作进度在进入后显示。

阅读设置中可自定义封面、字体、字号、行距、正文宽度、纸色和滚动/模拟翻页。目录切换章节，书签定位段落；阅读位置自动保存。模拟翻页使用分页排版，不是三维翻页动画。字形、DPI或窗口变化时重新排版，并尽量恢复原锚点。

右侧图像栏只使用图标展开/收起，向右隐藏。缩略图与浮层预览覆盖阅读区域，不挤压正文。资产预览从主卡开始，箭头浏览所有有图副卡，包含后续章节状态；标签标明状态，不会自动采用该状态。场景成果优先，候选可在设置中隐藏。关联依赖既有数据和本地匹配，不额外调用模型。

成果集新增编辑标题、说明、情节关联、替换图片、批量删除和恢复。替换图片立即保存，其他字段点击保存生效；删除保留原文件。目标情节已有成果时会阻止冲突关联/恢复。

## 数据与升级

继续使用原账户与项目目录，不升级数据库结构。阅读记录在项目配置和 `08_项目数据/阅读记录.json` 中保存；封面复制到 `01_原始资料/封面/`。成果编辑记录和删除索引在 `06_最终成果/` 下。升级前仍建议备份用户资料。

位置用章节、段落、字符偏移与短引文保存；原文改动后可唯一匹配时重定位，歧义或已归档章节提示复核，不猜测位置。封面和图片读取均限制在项目路径内。

## 验证

116项后端测试通过；真实 Qt WebEngine/QWebChannel 下验证原有制作全流程和新阅读流程，包括图片预览不改变正文几何、图标收起、分页书签、封面上传与重新打开恢复位置。未调用真实付费模型，未验证用户机器的 ComfyUI 或 Windows 运行环境。
