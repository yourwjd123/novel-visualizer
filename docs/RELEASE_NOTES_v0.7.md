# v0.7.0-beta.1 · 源码测试版（Windows 构建暂缓）

- 资产卡面支持个别/批量确认、锁定与解锁；完成本章整理时可明确批量确认，不再仅变更流程状态。历史建卡建议不随每次进入资产库弹出，已建条目不可重复提交。
- 人物卡分面容、体型、外观与状态、背景信息、关系；场景/道具卡分视觉描述与相关情节。背景关系不自动写进生图文本；旧内容保留供人工分类。
- 情节卡直接显示、添加、删除资产关联及选择副卡；移除仅解除关联，本地匹配尊重人工排除。本图出镜另行控制。
- 取消独立提示词生成流程，场景图/资产图各有工作区。最终方案直接用于生图，可编辑/AI扩写/查看提交内容；自动模板与补全校验排除推测、建议、待确认段落。用户仍应审核模型文本，规则校验不能保证理解所有自然语言。
- 图片按实际文件连续编号；ComfyUI reference_N映射对应真实上传文件，无图资产使用视觉文本。普通兼容图片API仍只文生图，须明确接受限制。
- 离线导出素材版本目录，保存最终MD、编号参考图、独立说明和清单，并可打开目录。导出正文与本程序提交正文共用构建逻辑；不需要配置接口或执行生成。
- 咨询不再支持历史引用，输入草稿按章节/模式/目标隔离；历史仍可查看导出。保留模型状态、token预估及实际usage。
- 默认提示词升级至5.0，去除旧场景模板的关键缺项输出，与最新分类字段和统一方案匹配；用户前置优先，个人模板不覆盖。

源码包含已编译前端，需要Python和requirements依赖。升级前备份资料；本轮同步GitHub源码与已编译界面，不创建Release，未启动Windows构建。真实付费模型及用户本机ComfyUI仍需用户测试。
