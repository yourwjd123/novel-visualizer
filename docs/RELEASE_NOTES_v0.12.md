# v0.12.0-beta.1 测试版说明

2026-11-19。完成本地界面编译并同步GitHub，不创建Release，不启动Windows构建。

## 连接管理

在语言模型配置/生图模型配置查看全部连接卡片，点击编辑参数和密钥，勾选默认对应节点，一次保存。图片连接保留生成前本次选择；ComfyUI卡片内管理工作流预设，可指定同连接、同参考图数量的默认项。独立节点参数、前置提示词、任务提示词及运行时用量功能保持。

卡片显示模型、地址和凭据状态，密钥不回显。已有系统凭据的连接在编辑时默认保持系统保存；复制不带密钥或节点绑定。删除列出影响，允许明确指定替代或解除；不静默回退。删除前后历史任务和成果不变，工作流保留为未绑定预设，可手动重新绑定，旧内嵌工作流也不自动迁移到新服务。

## 资产整理

章节建卡建议提供复用已有主卡、创建状态副卡、新建独立资产三种决策，目标以ID指定；同名不同人可独立存在。新增request_id把模型条目与用户勾选项对应，兼容唯一姓名旧输出，歧义不猜测。

同类型资产拖到目标底部明确高亮的投放区，成为目标副卡。原卡内容、来源、图片和额外参考图保留，原关联情节指定该副卡；其他章节不会自动采用。目标补充身份别名/出现位置供本地关联，不覆盖稳定视觉字段。原卡已有副卡时先整理，不创建多层嵌套；锁定卡先解锁；同情节同时引用两卡、出镜或状态矛盾时先核对再操作。

三点菜单的合并功能逐项选择冲突字段，保留图片、证据、别名、状态与副卡并重定向关联。原卡归档而非删除。操作后可撤销，或在资产操作记录/目标卡菜单恢复；先显示影响。恢复使用当前副卡编辑，保留后续人工修改；已改变的关联不直接用旧快照覆盖。原始记录和历史生成快照保留。写入失败回滚，准备/恢复中断日志在下次打开时恢复到可重试状态。

资产卡默认只显示缩略图、名称、简短描述、类别/等级、状态下拉、当前状态和副卡数。图片点击放大，文字点击编辑；制作图、合并、归入、删除和恢复放入图标或菜单，批量选择悬停/选中显示，触屏保留可见入口。长继承表述删去，选择项为“自动”，同时显示实际使用状态。
